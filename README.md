# MinVil

Projet de mod Minecraft autour d'une enquête villageoise : un crime entre PNJ, résolu à partir d'indices et d'alibis.

Pour l'instant, le dépôt contient un prototype Python du générateur de crime, dans `prototype/mystery.py`.

```
cd prototype
python3 -I mystery.py            # lance les tests
python3 -I mystery.py --seed 0   # affiche un cas
```

Contexte, choix de conception et prochaines étapes : voir [PASSATION.md](PASSATION.md).
